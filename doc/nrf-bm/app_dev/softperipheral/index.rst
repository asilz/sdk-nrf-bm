.. _bm_softperipheral:

Soft peripherals
################

Soft peripherals implement digital peripherals in firmware running on the Fast Lightweight Peripheral Processor (FLPR), a VPR core.
The application controls these peripherals through a driver running on the application core.

This chapter describes how to integrate a soft peripheral into an application developed with |BMlong|.
For additional information, see :ref:`soft_peripherals`.
